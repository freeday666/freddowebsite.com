
# Oranjestad Roleplay

Een eerste speelbare prototype van een 3D-browsergame.

## Benodigdheden

- Node.js
- Internetverbinding
- Een hostingdienst die Node.js en WebSockets ondersteunt

## Installatie

1. Upload alle projectbestanden.
2. Open een terminal in de projectmap.
3. Voer uit: npm install
4. Start de server met: npm start
5. Open de website op de server.

## Bediening

- Joystick: lopen en rijden.
- Auto: instappen.
- Uitstappen: terug naar lopen.
- Verander naam: kies je spelersnaam.

## Opmerking

Dit is een eerste prototype, geen complete GTA-achtige game.
