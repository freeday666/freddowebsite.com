# NovaDev — Free AI Chat

Een moderne, responsive chatinterface voor NovaDev. De pagina werkt zonder account en bevat voorbeeldknoppen voor Python, Node.js, PowerShell en Command Prompt.

> **Let op:** de huidige versie is alleen de chatinterface. Voor echte AI-antwoorden moet je een backend koppelen aan de chat.

## Functies

- Geen login of account nodig
- Responsive ontwerp voor mobiel en desktop
- Voorbeeldprompts voor programmeertalen en terminals
- Enter verstuurt een bericht; Shift + Enter maakt een nieuwe regel
- Geen externe JavaScript-bibliotheken nodig
